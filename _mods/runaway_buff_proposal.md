## 2. 机制流派设计

### 设计原则
1. **强化燃烧体系** - 提升燃烧DoT等级和叠加效率
2. **优化连击系统** - 从概率性预备改为确定性，提升战术可靠性
3. **路径差异化** - 三个路径有明确定位
4. **保持角色特色** - 燃烧DoT、位置移动、隐身机制

### 路径1：燃烧积累流 (Survivor)

**核心理念**：燃烧叠加 + 自我燃烧转化 + 团队燃烧辅助

**技能配合**：
- run_firestarter_p1：复制燃烧 (需消除冷却惩罚)
- run_hearthlight_p1：燃烧转化治疗
- run_backdraft_p1：群体燃烧爆发
- run_searing_strike_p1：自身燃烧触发机制

**战斗流程**：
1. 纵火者P1 (复制团队燃烧到敌人)
2. 炉光P1 (燃烧转化治疗)
3. 逆火P1 (群体燃烧爆发)
4. 灼痛打击P1 (自我燃烧触发特效)

**定位**：燃烧队伍核心，快速叠加燃烧并转化收益

### 路径2：隐身刺客流 (Blaster)

**核心理念**：隐身爆发 + 标记偷取 + 位置控制

**技能配合**：
- run_smokescreen_p2：嘲讽 + 双隐身 + 前进 + 刷新 (需消除冷却惩罚)
- run_ransack_p2：偷取标记 + 破格挡 + 拉近 (已优秀)
- run_searing_strike_p2：连击大燃烧 + 隐身暴击加成 (已优秀)
- run_hearthlight_p2：隐身触发再生

**战斗流程**：
1. 烟幕P2 (隐身+嘲讽+前进)
2. 灼痛P2 (连击大燃烧爆发)
3. 搜刮P2 (偷取敌人增益)
4. 炉光P2 (隐身消耗触发再生)

**定位**：前排刺客，隐身机制控制战场节奏

### 路径3：纯连击流 (Skirmisher)

**核心理念**：连击确定性 + 燃烧施加 + 位置干扰

**技能配合**：
- run_smokescreen_p3：预备连击 + 虚弱 + 致盲 + 隐身 (已优秀)
- run_ransack_p3：预备连击 + 拉近 + 前进 (已可接受)
- run_dragonfly_p3：群体燃烧 + 后退 + 隐身目标加成
- run_firefly_p3：中燃烧 + 隐身目标加成 (已可接受)
- run_searing_strike_p3：中燃烧 + 隐身目标加成 (已可接受)

**战斗流程**：
1. 烟幕P3/搜刮P3 (预备连击+控制)
2. 蜻蜓P3/萤火虫P3 (燃烧叠加+隐身加成)
3. 终结连击 (高伤害爆发)

**定位**：纯连击流，确定性预备机制+燃烧输出

### 流派对比

| 维度 | 路径1 (燃烧积累) | 路径2 (隐身刺客) | 路径3 (纯连击) |
|------|----------------|-----------------|---------------|
| **核心机制** | 燃烧叠加转化 | 隐身爆发偷取 | 确定性连击 |
| **战斗节奏** | 长期(4+回合) | 中速(2-3回合) | 灵活 |
| **生存能力** | 高(燃烧治疗) | 中(嘲讽+隐身) | 中(隐身) |
| **输出能力** | 燃烧持续 | 隐身爆发 | 连击爆发 |
| **团队贡献** | 燃烧辅助 | 标记控制 | 连击输出 |
