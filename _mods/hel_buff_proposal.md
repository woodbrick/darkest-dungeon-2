## 2. 机制流派设计

### 设计原则
1. **强化流血体系** - 提升流血DoT等级和连击协作
2. **优化控制技能** - 基础版增加完整控制效果
3. **路径差异化** - 三个路径有明确定位
4. **保持角色特色** - 流血DoT、位移攻击、winded机制

### 路径1：流血压制流 (Ravager)

**固有效果**：
- 最大生命值 **+20%**
- 1号位伤害 **+25%**
- 回合开始 **25%几率** 对随机敌人施加中等流血

**流血抗性削弱机制**（3层）：
1. 自身流血抗性 **+33%** (路径技能生效)
2. 目标流血抗性 **-30%** (条件：目标已连击)
3. 目标流血抗性 **持续削弱2回合** (升级版)

**核心理念**：流血抗性削弱 + 持续流血输出

**技能配合**：
- hel_if_it_bleeds_p1：降低敌人流血抗性 + 流血DoT
- hel_bleed_out_p1：大流血爆发 + 流血抗性削弱
- hel_breakthrough：破格挡 + 位移到位
- hel_howling_end：高伤害收割

**战斗流程**（配合固有效果）：
1. **回合开始**：25%几率自动流血触发
2. 若血则流P1 (3层流血抗性削弱 + 施加流血)
3. 突破 (破格挡 + 前进到1号位获得+25%伤害)
4. 流尽鲜血P1 (大流血爆发，抗性已削弱)
5. 凄厉终局 (收割残血，1号位伤害加成生效)

**定位**：流血队伍核心，削弱抗性+持续输出

### 路径2：暴击狂暴流 (Berserker)

**固有效果**：
- 最大生命值 **-10%**
- 死亡抗性 **+10%**
- 流血抗性穿透 **+33%** (路径技能生效)
- 暴击率加成失效 ⚠️ (路径技能移除berserker标签，不享受原版+10%暴击)

**核心理念**：流血抗性穿透 + 高伤害爆发

**技能配合**：
- hel_if_it_bleeds_p2：流血穿透 + 流血DoT
- hel_bleed_out_p2：流血穿透 + 大流血爆发
- hel_howling_end：高伤害收割
- hel_wicked_hack：基础输出

**战斗流程**（配合固有效果）：
1. 若血则流P2 (33%流血穿透生效，无视高抗性敌人)
2. 邪恶斩击 (连击启动)
3. 流尽鲜血P2 (穿透流血爆发，死亡抗性+10%提高生存)
4. 凄厉终局 (收割残血，注意-10%生命值风险)

**定位**：流血穿透输出，无视抗性高伤害

### 路径3：不死战神流 (Deathless)

**固有效果**：
- 回合开始：隐藏winded **+1**
- 回合结束：winded层数转换为格挡 (1-3层→1-3格挡)
- 被暴击时：触发压力治疗 (50%几率-1 / 25%几率-2)
- 嚎叫终结伤害 **-50%** (带carcass标签)

**核心理念**：格挡破坏 + 嘲讽坦克 + 持续生存

**技能配合**：
- hel_wicked_hack_p3：破格挡 + 伤害输出
- hel_barbaric_yawp_p3：虚弱 + 嘲讽 + 控制
- hel_toe_to_toe：嘲讽 + 前进
- hel_adrenaline_rush：治疗净化

**战斗流程**（配合固有效果）：
1. **回合开始**：自动获得隐藏winded+1
2. 正面对峙 (嘲讽 + 前进)
3. 野蛮咆哮P3 (虚弱控制 + 嘲讽，winded+1)
4. **回合结束**：winded层数(2)转换为格挡(2)
5. 邪恶斩击P3 (破格挡输出，格挡保护下安全攻击)
6. 受击时触发压力治疗（被暴击50%几率-1压力）

**定位**：前排坦克，格挡破坏+嘲讽控制

⚠️ **注意**：嚎叫终结伤害-50%，建议使用其他技能收割

### 流派对比

| 维度 | 路径1 (流血压制) | 路径2 (流血穿透) | 路径3 (不死战神) |
|------|----------------|----------------|----------------|
| **核心机制** | 流血抗性削弱 | 流血抗性穿透 | 格挡破坏+嘲讽 |
| **战斗节奏** | 长期(4+回合) | 中速(2-3回合) | 持续续航 |
| **生存能力** | 中等 | 低(-10%生命) | 高 |
| **输出能力** | 流血持续 | 穿透爆发 | 稳定输出 |
| **团队贡献** | 流血辅助 | 伤害输出 | 坦克控制 |
