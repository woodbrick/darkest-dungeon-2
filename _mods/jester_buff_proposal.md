# 小丑技能改进

## 1. 弱势技能评估

### 评估标准
- **DU 价值** < 9：弱势技能，需要增强
- **DU 价值** 9-13：可接受技能
- **DU 价值** > 13：优秀技能
- **升级版 (_u)**：期望 DU 为基础版的 **1.5倍**

### 当前技能 DU 评估

**作用范围标识**：
- `单体` - 攻击1个敌人
- `群攻×N` - 攻击N个敌人（伤害×N计算）
- `友军×N` - 对N个队友释放（效果×N计算）

**DU计算公式**：
- 群攻：DU = (基础伤害 × 目标数) + DoT + 效果
- 友军：DU = (效果价值 × 队友数) + 其他
- 单体：DU = 基础伤害 + DoT + 效果

## 2. 机制流派设计

### 设计原则
1. **强化连击系统** - 从概率性改为确定性，提升战术可靠性
2. **增强生存能力** - 移动/位移技能添加闪避
3. **路径差异化** - 三个路径有明确定位
4. **保持角色特色** - 连击系统、压力治疗、流血协同

### 路径1：连击控制流

**核心理念**：击退控制 + 连击终结 + 位置管理

**技能配合**：
- jes_echoing_march_p1：击退1+晕眩1 (6 DU)
- jes_harvest_p1：伤害4+流血中+预备连击 (11 DU)
- jes_solo_p1：结束连击+预备连击 (6 DU)
- jes_finale：伤害7-13+连击加成 (12+ DU)

**战斗流程**：
1. 回响进行曲 (击退+晕眩控制)
2. 收割/机智妙语 (预备连击+流血)
3. 终章 (高伤害终结)
4. 独奏 (结束连击+立即预备)

**定位**：控制型连击爆发，击退+晕眩干扰敌人节奏

### 路径2：连击续航流

**核心理念**：伤害追踪 + 连击刷新 + 持续输出

**技能配合**：
- jes_encore_p2：被动 - 伤害追踪恢复 (8 DU)
- jes_harvest_p2：伤害4+预备连击 (7 DU)
- jes_finale_p2：伤害7+复杂后续效果 (15+ DU)

**战斗流程**：
1. 收割 (预备连击)
2. 终章 (高伤害+连击刷新)
3. 安可 (被动恢复追踪)
4. 循环输出

**定位**：长期战斗，连击刷新机制持续输出

### 路径3：流血治疗流

**核心理念**：流血协同 + 压力治疗 + 团队增益

**技能配合**：
- jes_battle_ballad_p3：前进1+力量1+间奏流血+闪避1 (9.5 DU)
- jes_inspiring_tune_p3：压力治疗2+流血条件治疗2 (6 DU)
- jes_play_me_out_p3：后撤1+格挡1+间奏流血+闪避1 (8 DU)
- jes_solo_p3：预备连击+间奏流血+闪避1 (6 DU)
- jes_finale_p3_u：伤害10+对流血目标伤害加成 (15+ DU)

**战斗流程**：
1. 战歌/独奏 (施加间奏流血+增益)
2. 收割/切除 (叠加流血)
3. 励志曲 (流血条件治疗)
4. 终章升级 (对流血目标高伤)

**定位**：流血队伍核心，流血协同+压力治疗

### 流派对比

| 维度 | 路径1 (连击控制) | 路径2 (连击续航) | 路径3 (流血治疗) |
|------|----------------|-----------------|-----------------|
| **核心机制** | 击退+晕眩控制 | 伤害追踪刷新 | 流血协同治疗 |
| **战斗节奏** | 中速(3-4回合) | 长期(4+回合) | 灵活 |
| **生存能力** | 中等 | 中等 | 高(闪避) |
| **输出能力** | 爆发 | 稳定持续 | 流血协同 |
| **团队贡献** | 控制 | 伤害 | 治疗+增益 |
