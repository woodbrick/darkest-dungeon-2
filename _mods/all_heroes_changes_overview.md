# 暗黑地牢 2 英雄技能改动总览

## 概述

本次更新对游戏中所有 11 位英雄进行了技能调整，主要改动模式包括：
1. **基础属性增强**: 大部分英雄生命值 +5，速度 +1
2. **伤害提升**: 攻击技能伤害普遍 +1 或更多
3. **功能性增强**: 移除限制性条件，增加额外效果
4. **机制优化**: 冷却时间、目标范围、使用次数调整

## 英雄改动详情

### 1. 苦修者 (Flagellant) - 史诗级增强

**基础属性**:
- 生命值: 50 → 55 (+5)
- 速度: 3 → 4 (+1)

**主要改动**:
- 所有攻击技能伤害 +1，暴击率翻倍
- 收回技能变为多目标，冷却时间 1→2
- 救赎自残伤害 20% → 10%，增加压力治疗
- 忍受技能压力伤害减半，增加格挡效果
- 路径技能大幅增强，特别是酸雨伤害翻倍

## 改动趋势分析

### 增强模式
1. **伤害提升**: 所有英雄的攻击技能都有伤害提升
2. **功能性增强**: 减少限制条件，增加额外效果
3. **生存能力**: 基础生命值普遍增加
4. **机动性**: 速度提升改善行动顺序

### 平衡调整
1. **冷却时间**: 部分技能冷却增加，防止过于频繁使用
2. **使用限制**: 路径技能使用次数增加，提升实用性
3. **目标范围**: 部分技能目标范围调整，更精准或更广泛

## 总结

本次更新是一次全面的英雄技能平衡增强，所有11位英雄都获得了不同程度的提升：

**主要提升方向**：
1. **生存能力**: 绝大多数英雄获得+5生命值（麻风病人+4）
2. **机动性**: 大部分英雄获得+1速度，提升行动顺序
3. **输出能力**: 攻击技能伤害普遍提升+1或更多
4. **功能性**: 新增名称覆盖ID，部分英雄获得新效果

**英雄排名**（按提升程度）：
1. **史诗级增强**: 苦修者、盗墓贼
2. **全面增强**: 赫利俄斯、小丑、瘟疫医生、逃亡者、修女
3. **显著增强**: 神秘学者、步兵
4. **适度增强**: 强盗、麻风病人

整体而言，这次更新成功提升了所有英雄的实用性，通过标准化+5生命值+1速度的基础模板，配合各英雄特性化的技能调整，创造了更加平衡和多样化的游戏体验。
